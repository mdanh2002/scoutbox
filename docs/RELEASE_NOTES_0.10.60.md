# ScoutBox 0.10.60

0.10.60 is a focused UI and diagnostics patch on top of 0.10.59.

- Cleans Configuration > Search Sources > Forums by removing repeated Forum/software tags and aligning source checkboxes in a stable grid.
- Renames the Forums save button to "Save" while keeping the same compact button width.
- Adds View Past Results to the bottom-left action area of the Opportunity, Hidden Lead and Address Book re-evaluation dialogs.
- Adds Forum visibility to Search Activity with a searchable provider dropdown, provider-type icons, and a new multi-select Provider types filter.
- Adds Cloud Provider, Search Engine, Direct Search and Forum provider-type classification for Search Activity rows and exports.
- Keeps Reddit untouched and leaves the 0.10.59 native-first forum source ownership rules intact.

Routine future releases increment the patch component unless a planned schema/API break requires a minor bump.
