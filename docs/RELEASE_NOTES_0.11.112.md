# ScoutBox 0.11.112

- Fixes the **Statistics** date-filter icon so its highlighted/active state depends only on explicit **From** or **To** values.
- Applies the same date-only filter-icon state to **Resource Usage**.
- Selecting a preset period segment such as 1 hr, 24 hrs, 7 days, 30 days or All Data no longer highlights the separate filter button by itself.
- Typing or choosing either From/To date immediately highlights the filter button; clearing both removes the highlight.
- An unchanged active custom From/To range can still be cleared by clicking the filter button, preserving the existing apply/clear behavior.
- Preserves all chart-hover, Tracking Links, and other behavior from 0.11.111.

Next release: 0.11.113.
