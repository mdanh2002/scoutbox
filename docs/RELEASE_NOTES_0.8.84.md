# ScoutBox 0.8.84 Release Notes

ScoutBox 0.8.84 is a focused visual and data-presentation follow-up to 0.8.83.

## Changes

- Hidden Leads list column proportions repaired: Added no longer collapses, and Company Info / Summary have usable widths.
- Hidden Lead HTTP health badges now sit after the domain on the second company line.
- Hidden Leads now supports **Hide failed URLs** for non-HTTP-200 website records.
- Hidden Leads toolbar actions are right-aligned; website-domain blocking is labelled **Add to Blacklist** with matching prompts.
- Hidden Leads and Applications & Outreach exports moved to the table footer beside the rows-per-page control.
- Likely Old Opportunity detail cards no longer show the exact estimated date in the KPI; the date remains available in Post Age evidence.
- Address Book unread counts now follow the same visible-contact rules as the list, and country flag/name can be recovered from the originating Opportunity or Hidden Lead.
- Dashboard Recent Campaigns and list timestamps use tabular/monospaced numerals for cleaner alignment.
- Ask ScoutBox open state now highlights the launcher without a dangling arrow.
- Failed AI Requests where inference never started leave Runtime / Model blank.
- Existing ScoutBox 0.8.83 Company Info, Fit confidence, email repair, error grouping, country normalization/filtering, unread-row, and enrichment changes remain intact.
