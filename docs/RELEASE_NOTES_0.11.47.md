# ScoutBox 0.11.47

## Changes
- Applications & Outreach Status filter is now a searchable, Apply-first checkbox dropdown.
- Applications & Outreach Channel filter is now a searchable, Apply-first checkbox dropdown.
- Status and Channel filters support multiple selected values and preserve old single-value URLs.
- Applications & Outreach Read filter is now an icon button with a dropdown menu, matching Opportunities / Hidden Leads / Address Book.
- Applications & Outreach Mark as control is now an icon button with a dropdown menu, matching Opportunities / Hidden Leads / Address Book.

## Validation
- Static regression checks for the new Applications & Outreach filter/action behavior.
- Python AST parse and compileall.
- Docker Compose YAML parse.
- Shell syntax checks.
