# ScoutBox 0.9.6 Release Notes

## Resource Usage
- Corrected the current-values layout regression caused by an inherited column flex direction.
- CPU, RAM, GPU, Requests, Local Tokens, Cloud Tokens, Disk and GPU Model now use a stable responsive grid below the full-width chart.
- Preserves the solid Requests series and the resilient macOS host telemetry work from 0.9.5.

## Recycle Bin
- Top toolbar now contains filters only.
- Bottom toolbar uses three balanced zones: bulk actions left, Rows/Export/item count centre, pagination right.
- Delete Selected and Empty Recycle Bin have slightly different danger shades.
- Existing icon-only actions retain tooltips and accessible labels.

No database migration is added in 0.9.6.
