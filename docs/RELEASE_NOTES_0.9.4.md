# ScoutBox 0.9.4 Release Notes

## Resource Usage current-sample footer

The CPU/RAM/token chart footer is simplified into one compact summary area. The current-values grid now has normal horizontal padding. The separate Host RAM / Disk / GPU capacity line is removed because Host RAM duplicated the RAM value already shown in the current-sample grid. The duplicate Captured timestamp is removed because Last updated is already shown in the page toolbar. Disk capacity and GPU model remain together on the compact metadata line.

No database migration is added in 0.9.4.
