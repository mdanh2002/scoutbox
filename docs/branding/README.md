# ScoutBox branding assets

Short name: **ScoutBox**  
Long name: **Niche Opportunity Intelligence Portal**

The production logo is the symbolic compass/radar mark selected for v0.6.1. It is intentionally icon-first and contains no letters.

- `portal/static/portal/scoutbox-logo.png` — original generated logo asset.
- `portal/static/portal/scoutbox-logo-256.png` — optimized login/brand asset.
- `portal/static/portal/scoutbox-logo-64.png` — optimized sidebar/favicon/chat asset.

The login page, authenticated shell, browser favicon and site-wide chatbot use this logo.
