# ScoutBox 0.10.110

## Focus residual clustering

- Adds a residual Focus clustering pass for records that remain blank or Unclassified after the main balanced assignment.
- Expands deterministic topic families for Machine Learning, Technical Support, GTM Analytics, Healthcare Research, FinTech Engineering, Data Analytics and Cloud DevOps.
- Allows useful two-record residual clusters in mid-sized lists while continuing to reject singleton-heavy and generic Focus taxonomies.
- Re-runs a one-time upgrade Focus repair independently for Opportunities, Hidden Leads and Address Book.
- Keeps campaign names as naming inspiration only when the record content supports the topic.

## List footer polish

- Moves Hide failed URLs to the bottom-left footer area beside the Rows control for Opportunities, Hidden Leads and Address Book.
- Leaves page counts and navigation on the right side of the footer.
