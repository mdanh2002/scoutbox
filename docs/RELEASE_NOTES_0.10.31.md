# ScoutBox 0.10.31

0.10.31 improves Opportunity list filtering and health signals.

- Opportunity advanced filters persist in the authenticated session until Reset Filter or logout.
- Active filters show shown/hidden counts and the filter toolbar icon is visibly highlighted.
- Opportunity summary open icons sit immediately after summary text; Address Book hides successful domain HTTP badges.
- Scheduled Opportunity URL-health checks can mark HTTP 200 amber when the configured Discovery AI route determines the returned page no longer contains the job.
- Remaining malformed Naver role titles that contain JD sentences are conservatively repaired from grounded source titles or job URL slugs.

Routine future releases increment the patch component unless a larger version change is explicitly requested.
