# ScoutBox 0.11.37 Release Notes

## Fixes

- Statistics world-map zoom now supports 25% through 1000%.
- Map pins remain fixed-size while zooming so they do not balloon and obscure the map at high zoom levels.
- The zoom control label has enough space to display 1000% without clipping.
- Statistics **Opportunity Status** now renders as a pie chart with an inline legend.
- Statistics **Search Provider Summary** now renders as a pie chart with an inline legend.
- Re-evaluate toolbar tooltips for Opportunities and Hidden Leads are now brief.
- Recycle Bin list footer now places Rows, export, and total item count at bottom-left, aligned with the page navigation row.

## Compatibility

- No database migration required.
- No external map services are used.
