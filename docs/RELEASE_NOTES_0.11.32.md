# ScoutBox 0.11.32

Targeted UI hotfix for the 0.11.31 list-filter and re-evaluation-history changes.

## Fixed

- Campaign, Location, and Focus dropdown search now hides non-matching options reliably.
- Campaign and Focus option rows no longer reserve blank icon space.
- Location option rows keep the flag/icon column.
- Dropdown rows use slightly larger, cleaner text and keep checkbox, optional flag, name, and count aligned on one line.
- All-selected filter summaries now include total counts.
- Hidden Lead re-evaluation detail now uses a cleaner point-form summary with only useful non-zero counts.

No database migration is required.
