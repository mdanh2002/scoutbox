# ScoutBox 0.11.41

- Changed the Statistics Global Activity Map controls into a vertical top-left legend with per-layer checkboxes and map-pin color keys.
- Added a top-right **Export PNG** control for exporting the currently visible map layers as a high-resolution PNG rendered at maximum map zoom.
- Removed the numeric zoom scale from the map zoom control while keeping +/- zoom buttons.
- Kept map drag-to-pan, fixed-size map pins, richer map pin tooltips, and click-through behavior from 0.11.40.
