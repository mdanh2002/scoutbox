# ScoutBox 0.11.50

## Fixed

- Corrected z-index/stacking behavior for searchable checkbox dropdowns such as **All locations** and **All focuses** in Address Book.
- Closed custom dropdown controls now scroll underneath the sticky ScoutBox header in the same way as the adjacent Search field instead of painting over the page heading.
- Open dropdown panels still render above list/table content while remaining below the global header.
- Applied the same stacking contract to all shared checkbox multi-select filters, searchable select dropdowns, and country combobox popovers in main-content list views.

This release carries forward the 0.11.49 Global Activity Map fixes unchanged.
