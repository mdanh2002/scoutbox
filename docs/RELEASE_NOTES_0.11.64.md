# ScoutBox 0.11.64

- Global Activity Map markers are now click-first: the separate hover record tooltip is removed.
- Clicking a marker opens one clean location panel containing the record list directly.
- The panel shows up to five selectable records with their dates and always shows the total record count below.
- Opportunity and Hidden Lead entries continue to open their record pages; Address Book and Blacklist entries continue to use the existing record-edit destinations supplied by the map data.
- No discovery, location-resolution, map aggregation, or filtering behavior changed.
- Campaigns are explicitly excluded from map rendering; only Opportunities, Hidden Leads, Address Book contacts, and Blacklist records are accepted as map layers.
