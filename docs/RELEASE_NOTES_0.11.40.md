# ScoutBox 0.11.40

- Added drag-to-pan support for the Statistics Global Activity Map while keeping the offline SVG map and no external map services.
- Hid map scrollbars and moved layer controls to the top-left with margin.
- Enriched map pin tooltips with entry-specific details and click targets.
- Plotted blacklist entries individually where possible and added name/domain/date/url/scope/reason tooltip details.
- Added more major country, region, ocean and city labels to the offline SVG map and moved overlapping labels.
- Removed the extra horizontal divider under the Global Activity Map heading.
