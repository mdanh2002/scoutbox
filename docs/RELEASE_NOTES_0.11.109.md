# ScoutBox 0.11.109

- Refreshes the Tracking Links page with a fresh GET when **Add Tracking Link** closes, avoiding Firefox's POST resend confirmation and the blank-dialog state that could follow cancelling that confirmation.
- Removes the legacy 3px Short URL prefix offset so the Short URL compound field starts on the same x-axis as Blog base URL and Import links.
- Matches the **Scan DOCX** button height to the bordered DOCX uploader field.
- Preserves all Tracking Link generation, sizing, wording, DOCX scanning, action-icon, suffix-marking, and Blog base URL behavior from 0.11.108.
