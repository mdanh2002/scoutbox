# ScoutBox 0.10.49 Release Notes

0.10.49 fixes two focused UI issues identified after 0.10.48.

## Detail-page active job status rows

- Active outreach preparation on Hidden Lead detail pages now appears in a dedicated status row above the buttons.
- Active summary, company research, and translation status chips on Hidden Lead detail pages use the same row.
- Active application preparation and other running job chips on Opportunity detail pages now use the same pattern.
- This prevents queued/running status chips from interrupting the button group.

## Compact company-filter Best Fit

- Hidden Leads and Address Book company-filter dialogs now include a Best Fit button.
- The preset selects small-company buckets, younger company/domain-age buckets, and Unknown / Others.
- Reset and Apply behavior remains unchanged.
- No migration is required.
