# ScoutBox 0.8.15 release notes

0.8.15 is a quality and observability release over 0.8.14. It fixes the Resource Usage 500, strengthens host telemetry, makes Dashboard attention state actionable, and prevents confirmed dead or aggregate listing pages from becoming misleading Opportunities.

The release also improves Market Studies organization/country/summary handling, adds Opportunity contacts, confidence-gates post age, removes engine-side negative query operators, adds campaign status/counts, and refines Resource Usage token/provider visualizations.
