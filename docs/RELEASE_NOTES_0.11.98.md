# ScoutBox 0.11.98

- Removes icons from Dashboard summary cards and gives them the same centered number/label geometry as Resource Usage cards.
- Compacts Recycle Bin Item Type, Item Date and Date Deleted columns, preserves more space for Item Title/Info, and makes all Recycle Bin toolbox actions use the normal neutral toolbar treatment.
- Removes standalone low-value search prepositions such as `in`, `at`, `for`, `with`, `from`, `to`, `of`, `by` and `on` from outgoing provider queries while preserving quoted phrases, site scopes, domains and technical literals.
- Retires the broad `Retro Computing` Focus label. Existing derived assignments are cleared for normal blank-Focus regrouping, and genuine old-system evidence is normalized to the narrower `Vintage Systems` label.
- Renames the Tracking Links `Application` column to `Application / Outreach`.
