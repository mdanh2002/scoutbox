# ScoutBox 0.10.67

0.10.67 is a compact Search Activity filter-label patch on top of 0.10.66.

## Changes

- Changes the Provider Types dropdown summary to `All Provider Types` when every type is selected.
- Changes the Providers dropdown summary to `All Providers` when every provider is selected.
- Uses compact partial-selection summaries: `Provider Types: N/3 selected` and `Providers: N/M selected`.
- Uses `None` when a multiselect has no selected values.
- Slightly narrows the Search Activity provider filter dropdowns now that their summaries are shorter.

## Upgrade notes

No database migration is required for this release.
