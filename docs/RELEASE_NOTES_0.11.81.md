# ScoutBox 0.11.81

## Search Activity

- Renames the regional filter summary to **All Regions** and adds clear spacing between region codes and market names.
- Moves the total request count to the right side of the top toolbar without including it in the Outcomes label.
- Restores the server-backed date-range toolbar at the bottom center while preserving active text, provider, region, outcome, and page-size filters.

## Resource Usage

- Places Market Coverage directly between the Discovery Performance visualization and its table.
- Moves the latest `Captured` timestamp beside the **CPU, RAM & Tokens** title.
- Hides the redundant selected-period label before **Last updated** and removes the divider before the custom date fields.

## Navigation and About

- Removes the fixed sidebar copyright block so navigation can use the full sidebar height.
- Replaces the About-page marketing sentence with `Copyright ToughDev 2026`.

These changes are presentation-only except for restoring the existing Search Activity date-range filtering path. Discovery scheduling, telemetry collection, and source behavior are unchanged.
