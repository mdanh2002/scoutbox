# ScoutBox 0.9.8 Release Notes

## Recycle Bin
- Moves Blacklist, Restore, Delete Selected and Empty Recycle Bin together into the top-right toolbar.
- Keeps the four actions icon-only with their existing tooltips/accessibility labels and distinct Delete/Empty danger colors.
- Leaves Rows/Export/item count centered in the footer and pagination right-aligned.

No database migration is added in 0.9.8.
