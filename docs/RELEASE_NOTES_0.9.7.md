# ScoutBox 0.9.7 Release Notes

## Resource Usage
- Rebalances the current-value strip to seven items and gives RAM, GPU and Disk more horizontal room.
- Shows GPU utilization as `GPU (<model>): <value>` and removes the separate GPU Model cell.
- Full RAM and Disk used/total values are no longer ellipsized at normal laptop/desktop widths; narrow layouts still collapse responsively.

## Recycle Bin
- Moves Empty Recycle Bin back to the top-right of the filter toolbar.
- Keeps Blacklist, Restore and Delete Selected in the bottom-left action group.
- Keeps Rows/Export/item count centered and pagination right-aligned.
- Narrows the Search field to reduce top-toolbar crowding.

No database migration is added in 0.9.7.
