# ScoutBox 0.11.104

- Removes the large empty area at the bottom of Add Tracking Link when the dialog is first opened.
- Measures the embedded Tracking Link editor from its actual rendered content instead of the iframe/root viewport height.
- Lowers the obsolete 270px iframe floor so the initial three-row form can shrink naturally.
- Keeps dynamic growth for status messages and DOCX scan results, with scrolling only when the browser viewport is the limiting factor.
- Preserves all Tracking Link alignment, filename display, active date-filter styling, and Dashboard region-placement changes from 0.11.103.
