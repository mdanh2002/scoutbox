# ScoutBox 0.11.63

- Global Activity Map grouped markers now present the first five underlying records rather than showing only one record plus an ambiguous aggregate count.
- Hover text is concise: location plus record name/date lines. Opportunity/Hidden Lead status and Fit are no longer shown in map hover text.
- Clicking a grouped marker opens a compact record picker so each of the first five records can be selected individually.
- Opportunity and Hidden Lead entries open their ScoutBox detail pages.
- Address Book and Blacklist entries open their existing edit dialogs through a map deep-link.
- When more than five records share a marker, the map shows a simple remaining-record count such as “5 more records”.
- No discovery, location resolution, geography, selectivity, or map-placement behavior changed in this release.
