# ScoutBox 0.11.82

## About ScoutBox

- Replaces the plain copyright wording with a compact legal line: `© 2026 ToughDev. All rights reserved.`
- Uses a smaller type size and a restrained secondary color so the line reads as metadata rather than marketing copy.

## Market Coverage

- Removes the nested card appearance and presents Market Coverage as a flat subsection within Discovery Performance.
- Displays Languages first in a two-column legend, followed by Markets in a separate two-column legend.
- Removes the legend pane's internal scrolling so both groups use the available page height naturally.

This release changes presentation only. Market Coverage calculations, exports, refresh behavior, and discovery processing are unchanged.
