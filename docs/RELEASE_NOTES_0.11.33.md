# ScoutBox 0.11.33

Targeted UI hotfix for the Hidden Lead re-evaluation history detail panel.

## Fixed

- Kept the point-form summary only for the active queued/running Hidden Lead reassessment row.
- Removed duplicated Started on / Checked / Kept / Recycled / Strong Fit / Need review / Timed out blocks from completed Hidden Lead result entries.
- Completed Hidden Lead result entries now rely on the existing per-entry result table.

No database migration is required.
